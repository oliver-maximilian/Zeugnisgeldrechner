# Zeugnisgeldrechner

Mein allererstes richtiges Programm, entstanden 2021 im zweiten Jahr meines Fachabiturs in Informations- und Kommunikationstechnik.

Eine Java-Anwendung mit grafischer Oberfläche (Swing/AWT, keine externen Bibliotheken), die aus eingegebenen Noten das Zeugnisgeld berechnet. Der gesamte Code steckt in einer einzigen Datei mit rund 3000 Zeilen und enthält viel redundanten Code. Damals kannte ich weder Git noch Refactoring, und ich habe es bewusst so gelassen, wie es war.

## Ausführen

Voraussetzung ist ein installiertes JDK (11 oder neuer).

```sh
javac src/Zeugnisgeldrechner.java
java -cp src Zeugnisgeldrechner
```
